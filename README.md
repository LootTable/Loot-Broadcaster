# OSRS Broadcasts

RuneLite Plugin Hub project scaffold for an opt-in achievement broadcast plugin.

## Current state

This repository contains boilerplate only. Event detection, networking, validation,
moderation, persistence, overlays, and broadcast rules are intentionally not implemented.

## Requirements

- Java 11
- Gradle

## Development

Open the project as a Gradle project in IntelliJ IDEA. Run the `run` Gradle task to
launch RuneLite in developer mode with the plugin loaded.

## Build

```sh
gradle build
```

The project follows RuneLite's official example-plugin structure and avoids additional
third-party dependencies.
